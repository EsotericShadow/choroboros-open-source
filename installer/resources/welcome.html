Choroboros

Beta v2.05 by Kaizen DSP

This installer will place the Choroboros chorus plugin on your system. You will be able to choose which formats to install:

VST3 for Ableton Live, Cubase, Studio One, REAPER, FL Studio, Bitwig, and others.
Audio Unit for Logic Pro and GarageBand.
Standalone application for using Choroboros without a DAW.

The installer requires an administrator password because plugins are installed to system directories where all user accounts can access them.
